# AGENTS.md

## Commands

- `pnpm dev` - Start the dev server
- `pnpm build` - Build the app for production
- `pnpm preview` - Preview the production build locally
- `pnpm check` - Lint, check formatting, and typecheck
- `pnpm format` - Format the project
